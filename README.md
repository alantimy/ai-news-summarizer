# 📰 AI-Powered News Summarizer

An AI-powered web application that summarizes news articles into short, easy-to-read summaries.  
Built as a beginner-friendly AI project to demonstrate Python, NLP, and web app development skills.

---

## 🚀 Features

- Summarizes long news articles into short summaries
- Simple and clean web interface
- Built using Python and Streamlit
- Beginner-friendly and easy to run locally

---

## 🛠️ Technologies Used

- **Python 3**
- **Streamlit** – for the web interface
- **Natural Language Processing (NLP)**
- **Hugging Face Transformers** (pre-trained summarization model)
